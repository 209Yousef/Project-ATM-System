
# ATM System - C#

A console-based ATM simulation developed in C# as part of my programming learning journey through Programming Advices by Mohammed Abu-Hadhoud.

## About the Project

This project simulates basic ATM operations and focuses on applying programming fundamentals, problem-solving techniques, and structured code organization.

## Features

- User login and authentication
- Check account balance
- Deposit money
- Withdraw money
- Interactive console menu

## Technologies

- C#
- .NET / Console Application
- Visual Studio

## Learning Objectives

- Strengthen problem-solving skills
- Practice functions and conditional statements
- Work with loops and user input
- Organize code into reusable functions
- Build a practical console application
